# 📊 Real-Time Stock Market Dashboard

## 📌 Project Description

A Python-based stock market dashboard that retrieves stock market data using the Alpha Vantage API and displays it in an interactive Streamlit web application.

## 🚀 Features

- Select different stocks
- Display latest closing price
- Display opening, high, and low prices
- Calculate price change and percentage change
- Display trading volume
- Show historical stock data
- Display closing price trend
- Display trading volume trend

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Requests
- Alpha Vantage API
- python-dotenv
